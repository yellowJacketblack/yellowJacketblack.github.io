GIRL, the Butler

Multi-role authenticated analytics dashboard with role-based access control

Project Overview

GIRL, the Butler is a secure, multi-role business intelligence dashboard designed to serve different user types with tailored access levels. The application features authentication via LINE Login or email, ensuring that sensitive data and functionality are protected while providing a personalized experience for each user role.

The dashboard implements role-based access control (RBAC), routing authenticated users to role-specific interfaces that display only the data and tools relevant to their permissions. This architecture demonstrates enterprise-level security patterns while maintaining a clean, user-friendly experience.

User Roles & Access Levels

Seller

Report sales and view sales reports. Sellers can input transaction data and access their individual sales performance metrics.

Administrator

Manage prompts and view the full dashboard. Administrators have complete access to system configuration, prompt management, and all analytics across the platform.

Viewer

View dashboard reports. Viewers have read-only access to reports and visualizations, ideal for stakeholders who need insights without editing capabilities.

Key Features

  • Dual Authentication: Login via LINE OAuth 2.0 or traditional email authentication
  • Role-Based Access Control: Three distinct user roles with tailored permissions and interfaces
  • Role-Specific Routing: Users are automatically directed to their appropriate dashboard view after authentication
  • Sales Reporting: Sellers can submit and track sales data
  • Prompt Management: Administrators can manage system prompts and configurations
  • Read-Only Dashboard Access: Viewers access reports without modification rights
  • Secure Session Management: Authentication state maintained throughout user session

Tech Stack

Use Case

This dashboard architecture is ideal for:

  • Multi-tenant SaaS applications requiring different access levels for different user types
  • Sales teams needing individual reporting capabilities with administrative oversight
  • Organizations requiring secure, role-based data access with LINE integration
  • Client dashboards where stakeholders need view-only access to reports
